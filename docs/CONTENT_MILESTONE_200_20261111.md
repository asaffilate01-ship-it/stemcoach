# STEMCoach — 200 guided lessons milestone
Date: 11 November 2026

## Release scope
The learner-facing guided library expands from **176 to 200 substantive lesson records**, and from **974 to 1,166 authored formative self-check questions**. The additional **24 lessons / 192 Q&A** are written content, not merely parameter changes to the million-variant draft generator.

Each lesson has learning objectives, multiple explanatory paragraphs, a worked example, common mistakes, exam-focused tips, and eight interactive question–answer items with hints and explanations. The current local formats include multiple choice, multi-select, short text, numerical entry, true/false and ordering. No new dependency or AI model is required to grade them.

## Quality/release gates
- New lesson IDs, question IDs and subject/title pairs must remain unique; client catalogue and server lesson-context allowlist must match in order.
- Every new question must pass format/schema inspection and an authorised key must score as correct. Invalid answers and blanks must not be rewarded.
- Each hint, explanation, worked example and lesson paragraph must meet the content-length floor. These automated checks do not replace academic review of scientific truth or pedagogy.
- Existing test suites assert the full catalogue total **200 / 1,166**. Browser tests verify that displayed counts are not out of date.
- GitHub CI: typecheck, lint, Vitest, production build and Playwright mobile/desktop; then manual keyboard, 200% zoom, real-device and assistive-tech acceptance.

## Publication boundary and roadmap
**These are formative draft/self-check materials.** They are not independently reviewed or approved by AQA, Pearson, OCR or another awarding body and must not be silently merged with the paid/published exam question bank. The explicit server tutor-context allowlist permits reference to lesson IDs; it is not a certification of answers.

The medium-term targets remain **500 authored lessons** and **1 million distinct academically approved questions**:
- Guided lessons completed after this batch: 200 / 500, with 300 remaining.
- Authored lesson self-checks completed: 1,166. These are not equivalent to the paid published bank.
- Potential parameterised drafts: 1,048,576, as already generated by 16 numerical skill families. Mathematical variants are not a substitute for syllabus breadth, originality, professional review or server-side publication.
- Hosted approved-question inventory is still unverified until the correct STEMCoach Supabase environment and review audit are connected.

Recommended next authoring themes: applied assessment scenarios, literacy of scientific graphs, practical data interpretation, language/subject coverage gaps, and reviewed exam-board-specific mark schemes. Measure coverage by detailed curriculum outcomes rather than totals alone.

**Deployment boundary:** a successful GitHub merge proves the repository changed, not that the hosted application, database, remote indexes or native app builds were updated.
