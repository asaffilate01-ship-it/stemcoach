# Three-market premium programme
Scope: Pakistan grades 5–14 (institution-specific after HSSC), UK year 7 equivalent through bachelor's, Germany age 11 through master's. Preserve legacy learner access while new acquisition and authoring focus on these three markets. Targets PK 400k, GB 350k, DE 250k approved unique items; never count draft capacity as inventory.

## Delivery gates
1. Inventory canonical mascot assets and every direct image consumer. Preserve names and silhouettes; use shared avatar framing; test 320/390/768/1024/1440 widths, light/dark, keyboard and reduced motion. Review art visually before replacing it.
2. Map official versioned outcomes to country, jurisdiction, board, qualification, institution/module, stage, subject and language. Pakistan: all provinces, federal, AJK, GB and applicable international programmes. Sources: https://ibcc.edu.pk/registered-qabs-foreign-examination-boards/ ; https://www.kmk.org/ ; https://www.gov.uk/government/organisations/ofqual . Validate each qualification independently.
3. All markets: maths, biology, chemistry, physics, English language/IELTS, German/visa exam preparation, AI, coding, cyber security, cloud, commerce, accounting, business, economics. PK additional Arabic, Urdu, Turkish, Welsh; Welsh also relevant to Wales. Provide RTL for Arabic/Urdu and native review. Visa requirements vary and need dated official evidence.
4. Generate resumable batches into draft storage only. Require source outcome, original stem, answer, worked explanation, rubric, difficulty, language, provenance, duplicate fingerprint and reviewer decision. Independently verify numerical answers; moderate free-text and translated items; publish only reviewed items. Track authored, verified, reviewed, published separately. Targets 10k, 50k, 100k, 250k, 500k, 1m; audit coverage and rights at each gate.
5. Responsive learner dashboard, topic search, practice, mock exams, accessible diagrams, teacher review queues, parent reports and mastery progression. Keep mobile navigation predictable and assessment controls clear.
6. Evaluate open-source references (not dependencies yet): https://github.com/learningequality/kolibri offline learning; https://github.com/maths/moodle-qtype_stack symbolic assessment; https://github.com/shadcn-ui/ui responsive primitives; https://github.com/microsoft/playwright browser checks; https://github.com/langchain-ai/langgraph controlled agent workflows; https://github.com/modelcontextprotocol/servers MCP patterns. Review licenses/security before adoption.
7. Separate curriculum retrieval, lesson authoring, independent answer validation, duplication review, translation and tutor agents. MCP tools least privilege, no student identifiers sent to unapproved services, no automatic publication, prompt injection tests and audit logs. Cost caps, retries, idempotency and rollback.
8. Release only after CI, mobile/tablet/desktop screenshots, accessibility and database authorization tests. No claim of deployment without live verification.
